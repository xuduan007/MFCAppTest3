# MFCAppTest3

一个基于MFC框架的Windows应用程序，实现了以下功能：

## 功能特点

1. **欢迎界面**：显示一个欢迎图片和登录按钮
2. **随机数字生成**：在按钮上方每3秒生成一个新的6位随机数字
3. **数字输入验证**：右侧输入框只能输入数字，自动过滤非数字字符
4. **自动校验**：当输入6位数字时自动与随机数字比较
5. **结果提示**：校验正确或失败时弹出提示框
6. **统计功能**：左侧显示累积的校验成功和失败次数

## 项目结构

## 编译和运行

1. 使用Visual Studio打开项目
2. 选择合适的编译配置（Debug/Release）
3. 编译项目
4. 运行生成的可执行文件

## 使用说明

1. 启动应用程序后，会看到一个欢迎界面
2. 界面上方会显示一个6位随机数字，每3秒自动更新一次
3. 在右侧输入框中输入6位数字
4. 输入完成后系统会自动校验：
   - 如果正确，显示"校验正确！"并增加成功次数
   - 如果错误，显示"校验失败，请重新输入。"并增加失败次数
5. 也可以点击"登录"按钮手动触发校验
6. 左侧会实时显示成功和失败的累积次数

## 技术实现

- **MFC框架**：使用Microsoft Foundation Classes构建Windows应用程序
- **对话框设计**：使用资源编辑器设计界面布局
- **定时器**：每3秒生成新的随机数字
- **输入验证**：过滤非数字字符，限制输入长度为6位
- **消息处理**：响应按钮点击、输入框变化等事件

## 开发环境

- Visual Studio 2019或更高版本
- Windows 10 SDK
- MFC库
